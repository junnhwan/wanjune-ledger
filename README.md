# 一账 Android 安装包

这个仓库只用于发布一账签名 APK、更新校验元数据和更新说明，不包含源码、签名密钥或个人账本。

从 [Releases](https://github.com/junnhwan/wanjune-ledger/releases/latest) 下载正式 APK，按 Android 系统提示安装。也可在已安装的一账设置中检查更新。

应用标识固定为 cn.yizhang.ledger。后续升级直接覆盖安装，不要先卸载；升级前建议在设置中导出 JSON 备份。卸载或清除应用数据会删除本机账本。

账本保存在本机，断网可启动和记账。备份是包含个人收支的未加密 JSON，请放在受保护的个人存储中，不要上传到这个仓库。

系统及厂商行为存在差异，正式使用前请验证自己手机的保存、强制停止、重启、备份恢复和覆盖升级。

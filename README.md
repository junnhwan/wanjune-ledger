# 一账 · 把日子记清楚

一个本地优先的个人记账 App。记下每天的收支，用清楚的账单和图表了解钱花在哪里。

**[下载最新 Android APK](https://github.com/junnhwan/wanjune-ledger/releases/latest)** · Android 7.0 及以上 · 无需账号 · 离线记账

最新版本：[1.0.7（9）](https://github.com/junnhwan/wanjune-ledger/releases/tag/v1.0.7-9)。新增固定加速线路、失败回退和最多 4 路分段下载，保留跨月统计与图表修复。

## 主要功能

- 快速录入收入与支出，自定义分类、日期、时分和备注。
- 账单搜索与筛选、编辑、删除撤销，以及「再记一笔」。
- 按月、自定义起止日期或全部记录查看收支；支持跨月、跨年，以及近 7 天、近 30 天和今年快捷范围。
- 分类环形图、随时间跨度汇总的趋势图、可展开的金额/累计明细，以及对应范围账单；自定义时间与前一段等长时间比较。
- 可选月度总预算和分类预算，查看剩余额度与超支。
- 暗色、浅色和跟随系统；自定义日期与月份面板。
- 本机保存、JSON 备份与恢复、备份提醒和应用内更新；更新支持加速线路、自动回退、下载速度与校验状态。

## 安装与更新

从上方下载入口选择正式 `.apk`，按 Android 系统提示安装。已安装用户也可在设置中检查更新、下载并交给系统安装。

这次升级可使用[加速下载 1.0.7 APK](https://gh-proxy.org/https://github.com/junnhwan/wanjune-ledger/releases/download/v1.0.7-9/yizhang-1.0.7-9-release.apk)，或从上方官方发布页下载。新版下载器在安装 1.0.7 后生效；旧版本首次升级仍会使用旧下载逻辑。

查看任意时间段：进入「统计 → 自定义」，分别选择开始和结束日期，例如 10 月 4 日至 11 月 4 日（包含两端，共 32 天）。汇总、分类、趋势和明细会使用同一范围；月度预算切回「按月」查看。

后续正式版直接覆盖安装，**不要先卸载**。升级前建议导出一份 JSON 备份；卸载或清除应用数据会删除本机账本。包名固定为 `cn.yizhang.ledger`。

## 数据与备份

账本保存在本机，无需电脑或服务器在线；目前没有账号或跨设备云同步。JSON 备份是未加密的个人收支文件，请保存到受保护的应用外位置。恢复会替换当前账本，恢复前先另存备份。

不同手机的系统行为存在差异，正式使用前请确认保存、重启、备份恢复和覆盖升级正常。此公开仓库用于分发 APK、更新信息、介绍与截图，源码保存在私有仓库。
